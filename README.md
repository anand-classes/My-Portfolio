# Reeshav Anand — Sliding Puzzle Portfolio

## Preview locally
Open `index.html` in a browser.

## Puzzle image
The mountain-and-lake picture is already included at `assets/puzzle-image.jpg` and configured in `index.html`.
To use another permanent image, replace that file while keeping the same filename.

The puzzle is a classic 3×3 sliding puzzle: eight image tiles and one empty space. The shuffle is generated through legal moves, so the puzzle is always solvable.

## Publish with GitHub Pages
1. Upload the contents of this folder (`index.html`, `assets/`, and `README.md`) to the root of your GitHub repository.
2. Make the repository public if you are using GitHub Free and want to publish it with GitHub Pages.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub to show the published site URL in the Pages section.

Before publishing, replace the sample About/Projects text, add your `resume.pdf`, and update your LinkedIn URL. Do not publish secrets or private information.
